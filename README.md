# مشويات أبو الحديد — موقع المطعم (V1)

موقع عرض رقمي للمطعم (بدون طلبات أونلاين) مبني بـ React + TypeScript + Vite + Tailwind CSS v4 + Framer Motion.
الهدف: QR Code → الموقع → مشاهدة الفيديوهات + تصفح المنيو.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء للنشر

```bash
npm run build
```

الناتج في مجلد `dist/` — ارفعه على أي استضافة ستاتيك (Vercel / Netlify / Hostinger... إلخ).

## هيكل المشروع

```
src/
  components/   المكونات القابلة لإعادة الاستخدام
  data/         بيانات المنيو والفيديوهات وبيانات التواصل (menu.ts, videos.ts, restaurant.ts)
  types/        تعريفات TypeScript لبنية المنيو
  pages/        صفحة الهوم
```

## أشياء تحتاج مراجعتك

1. **رقم التليفون الثالث**: مطبوع على المنيو "0133188800" (10 أرقام فقط بدل 11) — تأكد من الرقم الصحيح في `src/data/restaurant.ts`.
2. **فيديوهات المطعم**: لا توجد روابط فيديو فعلية بعد. أضف رابط كل فيديو في `src/data/videos.ts` بالحقل `src`، ومدة الفيديو الحقيقية في `duration` (المدد الحالية تقديرية للعرض فقط).
3. **خلفيات الفيديوهات والهيرو**: بما إن مفيش صور/فيديوهات حقيقية للمطعم لسه، الخلفيات دلوقتي عبارة عن رسومات (SVG) مستوحاة من هوية المطعم (شواية، دخان، فلفل، سيخ) بدل صور فوتوغرافية وهمية. لما تتوفر صور أو فيديوهات حقيقية، ضيفها في حقل `poster` أو `src` في `videos.ts` وهتظهر تلقائيًا بدل الرسمة.
4. **صور الأطباق**: المنيو الحالي نصي بالكامل (بدون صور) بتصميم أنيق. أي عنصر `MenuItem` يقبل حقل `image` اختياري — إضافة صورة له لاحقًا لا تحتاج تعديل التصميم.
5. **شعار المطعم**: تم استخراج الشعار بخلفية شفافة تلقائيًا (كان مرفوع بخلفية بيضاء) — بيظهر دلوقتي بشكل طبيعي فوق الألوان الغامقة من غير أي دائرة بيضاء حواليه. لو حبيت نسخة أعلى جودة أو معدّلة، استبدل `src/assets/logo.png`.
6. **روابط السوشيال ميديا**: أيقونات فيسبوك/انستجرام/تيك توك في الفوتر موجودة بس بدون روابط حقيقية (`#`). حدّث الروابط في `src/data/restaurant.ts` (حقل `social`) لما تتوفر.

## المنيو: عرض الكل مقابل فئة واحدة

زرار "الكل" في أعلى المنيو بيعرض كل الفئات في شبكة (masonry). الضغط على أي فئة تانية بيعرضها هي بس بشكل موسّع وواضح. البحث بيشتغل بشكل مستقل ويطلع النتائج من كل الفئات.

## الجاهزية لقاعدة بيانات مستقبلية

كل بيانات المنيو تأتي من `src/data/menu.ts` وتُمرَّر كـ `props` للمكونات (`MenuSection` → `MenuCategory` → `MenuItem`).
لاحقًا يمكن استبدال هذا الملف بطلب API/قاعدة بيانات يرجع نفس الشكل (`MenuCategory[]`) بدون تعديل أي مكون واجهة.
