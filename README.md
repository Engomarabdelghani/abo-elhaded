# مشويات أبو الحديد — موقع المطعم (V1)

موقع عرض رقمي للمطعم (بدون طلبات أونلاين) مبني بـ React + TypeScript + Vite + Tailwind CSS v4 + Framer Motion.
الهدف: QR Code → الموقع → مشاهدة الفيديوهات + تصفح المنيو.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء للنشر
